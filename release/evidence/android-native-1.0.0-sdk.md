# Android SDK 독립 검수 결과

부분 완료다. 실제 SDK 연결, UMP 응답 처리, 전면과 보상형 Test Ad 표시, 완료 보상 60젬 한 번 지급, 광고 종료 후 게임 복귀를 확인했다. 추가 20분 제안의 모든 시나리오가 통과한 것은 아니다.

- 후보: `0823aaeeb104851b36fc025a74df50bc4b5b7a18`, `1.0.0 (1)`, 설정 지문 `e7b3bd5e6713a049addf519eaf43ff05ae7f05630b40b80cd1f7a1ff355b634c`.
- 사용 산출물: 같은 서명 AAB에서 만든 로컬 APK `95eb152e607ea8d5615e5bc3acc726e2dcdb743a0f7835d0a060aa66c2f139c0`. 629개 전체 페이로드의 바이트 일치를 확인했다. 업로드키 서명이며 adb 설치다. Play Store 설치 근거로 사용하지 않는다.
- 실행: 2026-10-21T12:28:33.475242Z부터 2026-10-21T12:45:20.540410Z까지 1007.065초. 이전 1151.120초를 보존한 누적은 2158.184초다. 공개 후 300초는 미사용 예약이다.
- 복원: 2026-10-21T12:44:01.752451Z에 원래 Play 서명 APK 설치를 마쳤고 2026-10-21T12:44:35.517447Z에 버전과 기존 서명 기록을 확인했다. 앱은 실행하지 않은 정지 상태다. 복원 APK 해시는 `dff8b9e734d80c82fe67112c176056d91ca10bb359eadcd91ff81524ce829053`다.

실제 UMP 로그의 `consentModeValues=4444`, `gdprApplies=0` 저장을 관찰했다. 명시 ConsentStatus enum은 노출되지 않았고 동의창도 표시되지 않았다. 이를 NOT_REQUIRED enum이나 필수 동의창 표시 통과로 확장하지 않는다.

두 번째 세션에서 실제 입력으로 4턴과 후속 이벤트, 학기 정산을 마친 홈 전환에 전면 Test Ad가 표시됐고 닫기 후 홈으로 돌아왔다. 보상형 Test Ad 완료 후 젬은 60에서 120으로 증가했고 일일 보상 버튼이 사라졌다. 첫 취소 의도 입력은 5초 기준 뒤여서 완료로 판정했다. 다음 광고에서는 Test Ad 확인 후 1.719초에 Back을 입력했으나 광고가 계속 표시됐다. 보상 전 취소와 무보상은 미확인이다.

60초 미만 보상형 차단과 보상형 후 180초 전면 억제는 기기에서 검증하지 않았다. 원 설계의 취소와 캡 규칙은 기존 개발 환경 근거와 구분한다. 48턴 UI 여정과 40엔딩 코어 경로도 별도 개발 환경 결과이며 이번 실행은 광고 최소 경로 5턴이다.

화면 전송 중 잘린 PNG와 connection reset 오류를 보존하고 일반 검수를 중단했다. 앱 오류로 단정하지 않는다. 자체 앱 로그는 12:32:30 UTC 무렵까지만 수집됐으므로 이후 광고 판정은 직접 본 화면과 실제 입력 기록에 근거한다.

중앙 기기 하한에는 실제 통과한 SDK 연결, UMP 응답 처리, 두 광고 형식 표시, 완료 보상과 복귀만 제출할 수 있다. 최종 중앙 검증은 부모 에이전트가 수행한다. 전체 공개와 공개 후 실행 확인은 미완료다. 추가 기기 실행은 승인되지 않았다. 계정과 serial은 이 공개용 요약에 포함하지 않았다.
