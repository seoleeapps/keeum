## 필요성과 영향

개발 환경에서48턴 실제 입력, 저장, 광고 실패와 중복 콜백,40엔딩 코어 경로는 검수했다. 실제 Android singleton, UMP와 GMA 응답, 실제 테스트 광고 로드와 전면 표시, 닫기 복귀, 보상 지급은 기기에서만 남았다. 앞선 Play 생성 APK의 adb 설치는 설치 출처 보호에 막혔으므로, 같은 CI AAB의 게임 에셋과 코드 바이트를 보존한 로컬 APK로 이 항목만 분리해 확인한다.

현재 Play 서명 설치본과 로컬 업로드키 서명은 다르다. 승인 후 해당 패키지만 삭제해 검수 데이터와 서명 기록을 지우고 로컬 APK를 설치한다. 끝날 때 로컬 설치본과 이번 검수 데이터만 삭제하고 정확한 원래 Play 서명 APK를 재설치한다. 합계 두 차례 서명 교체이며 두 삭제 모두 검수 데이터가 사라진다. 개인 저장 내용을 읽거나 백업하지 않는다. 예상 밖 버전, 서명, 설치본이나 사용자 데이터 우려가 생기면 삭제 전에 멈춘다. 다른 앱, 계정과 OS 설정은 바꾸지 않는다.

## 시간과 실행

기존 실제 누적 1151.119726초(19분 11.120초)를 보존한다. 새 구간은 최초 adb부터 최대20분이며 대기, 설치, 로그 수집과 마지막 복원을 모두 포함한 연속 벽시간이다. 공개 후5분은 별도 예약을 유지한다. 제안 최대 합계는 2651.119726초, 44분 11.120초다. 새 승인 전에는 새 타이머를 시작하지 않는다.

실제 Test Ad 표시를 확인한 광고만 취소나 완료하며 실제 광고 클릭, 결제는 하지 않는다. 앱 UID/PID 로그와 자체 화면만 수집한다. SSID, 비밀번호, 계정 값, 다른 앱 화면은 공개용 보고서에 넣지 않는다. 시계 변경, 저장 주입이나 내부 함수로 세션과 광고 조건을 우회하지 않으며 전체48턴은 반복하지 않는다. 시간이나 광고 준비 문제로 못 한 항목은 미실행/차단으로 남긴다.

현재 어댑터는 UMP 상태를 직접 출력하지 않는다. SDK 원문에서 실제 상태가 확인되지 않으면 미확인으로 기록한다. 창이 없다는 이유로 NOT_REQUIRED나 동의 창 표시 통과를 만들지 않는다. 실제 중복 콜백은 인위적으로 주입하지 않고 기존 개발 환경 검수와 구분한다.

원래 Play 서명본 복원이 실패하면 native 검수 통과 여부와 별개로 복원 실패를 보존하고 마감 전에 알려야 한다. 새 승인 없이 시간, 기기, 설치본, 계정이나 설정 범위를 늘리지 않는다.
