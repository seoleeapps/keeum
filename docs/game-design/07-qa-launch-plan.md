# QA 론칭 계획

- 제품명: 내 새끼 대학 보내기 (app-id: keeum)
- 문서 상태: approved
- 버전/수정일: v2 / 2026-10-21
- Source of truth: 한국 Google Play 첫 출시의 검수 범위와 공개 판정. 실행 상태와 근거는 [출시 상태](../../release/launch-status.md).
- Open blockers: 실제 Android 광고 검수. Seeker의 제거된 디버그 앱에 남은 데이터 처리 승인 대기.
- 승인 근거: 2026-10-21 사용자가 전달한 첫 출시 계획 구현 지시와 후속 “승인한다”. 데이터 삭제는 이 승인에 포함되지 않음.

DEC-038~042와 [구현 설계](../design/2026-10-21-google-play-launch/design.md), 같은 폴더의 test-plan.json을 따른다. 기존 IAP, Firebase, 클라우드 저장, 지표 수집, App Store와 AppsInToss 검수는 이번 출시 범위에서 제외한다. 이 문서는 그 승인으로 대체된 이전 QA 요구를 정리한 것이다.

## 기기와 플랫폼 매트릭스

| 대상 | 실행 범위 | 현재 상태 |
| --- | --- | --- |
| Godot 4.7.2 개발 환경 | 전체 회귀와 실제 클릭, 터치, 드래그 입력 | 후보 0823aae의 CI와 독립 코어 통과 |
| 렌더링 1080×1920 | 기본 글자, 시작부터 다음 아이까지 | 독립 1회차 재확인 통과 |
| 렌더링 1080×1600 | 가장 큰 글자, 목록 스크롤과 하단 버튼 | 독립 2회차 재확인 통과 |
| 렌더링 1080×2400 | 긴 화면의 같은 입력 여정 | 독립 3회차 통과 |
| Android 한 대 | 개발 환경으로 확인할 수 없는 실제 SDK, UMP와 광고 복귀만 | Seeker의 기존 패키지 기록 때문에 설치 전 정지 |

Android는 API 24 이상, 출시 target API 36이다. 전체 게임의 기기 회귀, 다른 기기와 iOS는 승인 범위에 없다. 이미 승인한 기기 시간은 최대25분이며 SDK 20분과 공개 후 5분으로 나뉜다. 추가 데이터 삭제 승인 요청은 사용한 약 2분에 이어 최대 18분 검수와 공개 후 5분을 제시했다. 승인 전 삭제나 교체를 하지 않는다.

## 기능 QA

활동 24종, 이벤트 48개, 엔딩 40개와 전용 CG 12장을 확인한다. 성장 공식과 가상 네이밍은 유지한다. 엔딩의 우선순위 중복과 도달 불가능 조건을 검사하고 각 48턴 코어 경로40개를 재생한다. 대표 UI의 48턴 완주와 구분해 기록한다.

뽑기는 무료 재화만 사용한다. 단차 150젬과 10연차 1350젬, 확률 3%, 17%, 80%, 천장 40과 마일리지를 결정적 검사로 확인한다. 표기와 추첨 로직을 대조하고 부족 재화 무차감, 실제 무료 젬 차감을 검수한다.

저장 후 재실행, 손상 저장과 백업 복구, 구버전, 미완료 이벤트와 전환기 복원을 코어 검사로 확인한다. UI 재시작 때 current_step이 빈 값이었던 근거를 미완료 이벤트 복원 근거로 쓰지 않는다.

보상형은 활동 보너스와 홈 일일 60젬이다. 하루 1회 젬, 세션 8회와 하루 18회, 60초 간격을 확인한다. 완료 한 번만 보상하고 취소, 실패, 광고 없음과 중복 입력은 무보상이다. 전면 광고는 두 번째 세션부터 학기 정산과 후속 이벤트 뒤 홈에서만, 180초 간격과 세션 2회,하루 4회다. 보상형 종료 후 180초도 확인한다. 가족 컷, 전환기와 엔딩에서는 광고와 꾸미기를 표시하지 않는다.

## UX와 접근성 QA

새 화면과 변경 화면은 구현자와 다른 검수자가 계획을 먼저 쓰고 3회 실행한다. 최종 후보의 각 회차는 입력 300단계와 PNG 11장을 남겼다. 원래 차단과 아트 누락 실패를 보존하고 같은 회차의 수정 재확인을 연결했다. 현재 미해결 UI 결함은 발견하지 않았다.

작은 화면과 긴 화면, 최대 글자, 목록 드래그와 고정 버튼, 실제 아트와 소리를 확인한다. 화면 이동이나 버튼 처리를 내부 함수 호출로 대체하지 않는다. TTS처럼 출시 화면에서 제거한 안내를 지원 기능으로 주장하지 않는다.

## 성능과 안정성

프로세스별 저장 경로와 프로젝트를 격리한다. E2E는 시간 제한과 실패 종료 코드, journey.json과 CI 링크를 남긴다. import, compile, 기존 코어와 UI 스모크, 실제 리소스 검사와 종료 시 오류를 확인한다. macOS의 cold/warm 캐시와 동시 생성도 별도 회귀 근거를 남겼다.

기기30분 발열 검사나 3티어 회귀를 요구하지 않는다. 프레임 수치, ANR과 크래시 프리 비율은 측정하지 않았고 통과 수치로 만들지 않는다. Firebase와 Crashlytics를 추가하지 않는다.

## 개인정보 정책과 연령등급

로컬 저장이며 로그인과 계정 생성이 없다. 초기화와 앱 제거의 저장 및 복구 백업 영향을 개인정보처리방침에 적는다. 광고 SDK의 데이터 전송은 게임 이용 지표 서비스와 구분해 신고한다.

등급 전략은 실제 15세 목표와 성인 마케팅이다. 투약 행위와 효과를 구체적으로 연출하지 않으며 실존 약품, 대학, 학원과 강사 이름을 쓰지 않는다. 실제 IARC 응답 결과는 한국 전체이용가였고 목표 15세와 구분한다. 원하는 등급을 얻으려고 설문을 바꾸지 않으며 최종 심사 결과를 다시 확인한다.

## 스토어와 정책

Seolee Apps 개인 계정의 `com.seorilabs.keeum`만 사용한다. 최종 서명 AAB에서 package, version1.0.0/code 1, API 36, debug=false, 운영 AdMob ID와16KB ELF 정렬을 읽어 확인했다. 재생성 원본 아트와 오디오, 테스트 코드는 내보내기에서 제외했다.

소개 문구, 아이콘, 기능 그래픽과 실제 실행 화면 3장을 API로 대조했다. 개인정보, 광고, 데이터 보안, IARC, 타겟층과 광고 ID 선언을 저장했다. 최종 Console은 조치된 선언 10개, 주의 필요 0개였다. SDK의 광고, 분석과 사기 예방 목적 및 TLS를 공식 GMA Next-Gen 설명과 대조했다. 자체 분석 SDK나 원격 설정을 추가하지 않는다.

AdMob 앱과 광고 단위, 동의 메시지, app-ads.txt, 스토어 연결과 실제 게재는 별도로 기록한다. 공개 전 패키지 검색에서는 연결할 스토어 결과가 나오지 않았다. 광고를 사용할 수 없어도 게임을 계속 진행해야 한다.

## 출시 포지셔닝과 획득

기존 부모 시점의 그림책 육성 방향과 성인 대상 소개를 유지한다. 24활동,48이벤트,40엔딩,CG 12장, 무료 젬 꾸미기와 로컬 저장처럼 구현하고 확인한 기능만 등록 문구에 쓴다. 광고 집행과 외부 모집 메시지 발송은 이 출시 작업에 포함하지 않는다.

## 현지화와 고객지원

첫 출시는 한국과 한국어로 한정한다. 지원은 cs@seorilabs.com과 [지원 페이지](https://www.seorilabs.com/support/), [개인정보처리방침](https://www.seorilabs.com/apps/keeum/privacy/)을 사용한다. 결제와 구매 복원 FAQ를 출시 기능으로 안내하지 않는다.

## 소프트론칭

동일한 서명 AAB를 내부 테스트에서 검수한 뒤 한국 전체 공개로 진행한다. 현재1.0.0(1)은 internal completed이고 기존 내부테스트 그룹 2명을 연결한 활성 상태다. 임시 앱 이름과 검토되지 않음 표시는 공개 심사 완료와 구분한다.

리텐션과 온보딩, 광고 시청률은 미측정이다. D1 목표나 크래시 프리 가설을 실제 통과 수치나 공개 조건으로 쓰지 않는다. 필요 없는 분석 서비스를 이 수치를 채우기 위해 추가하지 않는다.

## 론칭 게이트

1. 콘텐츠 완성, 같은 후보 SHA의 CI 전체 E2E와 독립 화면3회 통과.
2. 실제 Android SDK, UMP 응답과 필요한 동의 창, 테스트 광고 종료와 게임 복귀 확인. 미실행을 개발 대역 검사로 대신하지 않음.
3. 최종 AAB 서명, API 36,16KB와 운영 ID, 저장 원본 제외 검사 통과.
4. 마켓 문구와 실제 화면, 개인정보, 데이터 보안과 등급 선언 일치.
5. 같은 versionCode의 내부 처리와 필수 QA 뒤 심사, 승인, 한국 전체 공개.
6. 최종 한국 공개 스토어 조회와 승인된 같은 기기의 최소 실행 확인.

중앙 before-build와 내부 before-deploy 검증은 L3를 통과했다. 현재 before-release는 Android 광고 검수 때문에 열려 있다. 빌드, 업로드, 심사, 승인, 공개와 광고 게재를 서로 대신하지 않는다. [실행 근거](../../release/evidence/google-play-1.0.0.json)를 참고한다.

## 롤백과 운영

태그 receipt와 정확한 AAB 해시를 유지하며 재빌드 없이 같은 versionCode를 승격한다. 최초 공개는 한국 전체 배포이며 단계 출시로 임의 변경하지 않는다. 저장 손실이나 실제 차단 오류가 있으면 해당 후보의 사실을 기록하고 수정과 새 후보 검수를 거친다.

광고 설정은 로컬 데이터다. 원격 설정으로 즉시 끌 수 있다고 주장하지 않는다. 저장 백업과 기존 기기 데이터를 보호하며 승인 범위 밖의 초기화는 하지 않는다. 지원팀 연락과 추가 기기 사용은 기존 출시 승인으로 확대하지 않는다.
