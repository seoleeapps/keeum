# macOS 격리 실행의 리소스 캐시 수정

독립 검수 후보 `55528fac54576a2f6b964953b0d5a21305c197f6`에서 입력 여정은 통과했지만 실제 그림이 프로시저 폴백으로 보였다. 기존 캐시가 `.godot`과 폰트의 `.import`만 복원해 PNG와 오디오의 경로 정보가 빠졌다.

리소스 로드 검사를 먼저 추가한 실행에서 최초 import는 통과하고 같은 캐시의 재실행은 CG 12장, 계절 배경 4장, 오디오와 캐릭터 로딩 실패를 기록했다. 수정 후 두 실행 모두 해당 검사를 통과했다. 같은 캐시에 동시에 import하는 두 프로세스도 각각 성공했다. 세부 로그와 journey.json은 작업별 `build/cache-red-*-v2`, `build/cache-green-*-v2`와 외부 검수 증거로 보존한다.

수정은 엔진 버전, 코드와 런타임 리소스로 캐시 키를 만들고 모든 `.import`의 상대 경로를 함께 복원한다. 완성된 디렉터리만 원자적으로 공개하며, 각 실행의 프로젝트와 저장 경로는 계속 격리한다. `.gdignore` 아래 아트 원본은 import와 캐시 키에서 제외한다.

실제 오디오가 복원된 렌더링 실행에서는 종료 직전 효과음의 재생 참조가 남는 오류도 확인했다. 종료 전에 재생을 중단하고 오디오 믹서를 기다리는 정리 경로를 추가했다. 오디오 파일을 테스트 대역으로 교체하지 않는다.

CG 5장의 부모 표현도 아트 원장의 손, 뒷모습, 실루엣 규칙으로 수정했다. `raw/*-v1.png`에 첫 생성 원본을 보존하고 수정 출처를 asset-manifest.json에 기록했다. 새 6장은 final_canvas를 지정해 실제 1920×1080으로 맞췄다. 정적 아트 판정은 최종 후보의 게임 실행 통과를 대신하지 않는다.

최종 검수는 병합한 같은 후보 SHA의 CI와 독립 실행 3회로 다시 증명한다. Android SDK와 UMP, AAB 서명, 업로드와 공개는 이 개발 수정의 통과와 별개다.
