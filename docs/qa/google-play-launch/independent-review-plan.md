# 변경 화면 독립 실행 계획

승인된 L3의 새 화면 검수 3회다. 구현자는 코드 수정과 자체 검증을 수행했다. 독립 검수자는 같은 후보의 실제 명령과 PNG를 확인한다. 기기는 사용하지 않는다. 각 회차의 실제 후보 SHA와 시작 시각은 실행 전에 별도 보고서에 기록한다. 실패는 보존하고 수정과 재확인 근거를 연결한다. 3회 뒤 미해결이면 추가 회차를 임의로 시작하지 않는다.

| 회차 | 관점과 환경 | 실행과 기대 결과 |
| --- | --- | --- |
| 1 | 처음 사용자, 1080x1920 | 실제 시작 장면의 입력 E2E와 코어 검사. 48턴, 입시, 엔딩, 도감, 다음 아이. 광고 없이 완주, 취소 무보상, 중복 완료 1회, 무료 젬 차감과 저장 복원. 화면과 행동의 의미가 맞아야 한다. |
| 2 | 작은 화면과 큰 글자, 1080x1600, 글자 크기 최댓값 | 같은 전체 여정. 카드 위 드래그, 스크롤 뒤 선택, 버튼 가림, 안내 메시지의 입력 차단과 줄바꿈, 구매 문구 제거와 확률 고지를 확인한다. |
| 3 | 반복 사용자, 긴 화면 1080x2400 | 같은 전체 여정과 저장 복구 코어 검사. 이전 회차의 결과와 도감, 재시작, 광고 실패 뒤 일반 진행이 연결돼야 한다. |

각 회차 시작 전 다음을 기록한다: `git rev-parse HEAD`, 역할, 명령, viewport, 격리 user://, 증거 폴더와 예상 결과. 실제 입력은 `tools/e2e/journey.gd`, 40엔딩의 48턴 코어 재생과 오류 경계는 `tools/launch_checks.gd`다. `journey.json`은 완료 상태이고 모든 시나리오가 passed여야 한다. exit 0뿐 아니라 Godot ERROR와 SCRIPT ERROR가 없어야 한다. PNG를 직접 보며 기능과 UX 판정을 따로 기록한다.

실행 예시:

```sh
KEEUM_E2E_OUT="$PWD/build/qa/round-1" bash scripts/run_e2e.sh --capture
KEEUM_E2E_OUT="$PWD/build/qa/round-2" bash scripts/run_e2e.sh --capture --height 1600 --large-text
KEEUM_E2E_OUT="$PWD/build/qa/round-3" bash scripts/run_e2e.sh --capture --height 2400
```

원본 아트와 사용자 저장은 보존한다. 검수 저장은 실행 스크립트가 출력한 keeum-test 전용 경로이며 종료 후 해당 실행 소유 경로만 제거된다. 최종 공개용 실제 Android 광고 SDK, UMP 동의 창과 광고 복귀는 이 개발 검수 통과와 구분하고 별도 기기 사용 승인 후 남은 항목만 확인한다.
